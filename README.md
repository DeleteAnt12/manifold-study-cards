# Гладкие многообразия — карточки и билеты

Статический сайт: 64 карточки и 7 билетов. Работает на компьютере и телефоне. Сборка, Node.js и GitHub Actions не нужны.

## Публикация через GitHub Pages

1. Распакуй архив. Создай репозиторий на GitHub (проще — публичный).
2. Загрузи **содержимое папки**, а не сам ZIP и не папку целиком: `index.html`, `styles.css`, `app.js`, `data.js`, `vendor`, `README.md`, `.nojekyll`, `.gitignore`. Файл `index.html` должен быть в корне репозитория. Скрытые файлы начинаются с точки; при необходимости включи их отображение.
3. Сохрани файлы в ветке `main`.
4. Открой **Settings → Pages → Build and deployment**. Выбери **Source: Deploy from a branch**, ветку **main**, папку **/(root)** и нажми **Save**.
5. Дождись публикации: ссылка появится в разделе Pages. Её можно отправить друзьям; на телефоне сайт открывается по той же ссылке.

Все ссылки на ресурсы относительные: сайт подходит и для страницы проекта в подпапке GitHub Pages. Если твоя ветка называется иначе, выбери её вместо `main`.

## Локально

Открой `index.html` в браузере, сохранив рядом остальные файлы и папку `vendor`. Внешние шрифты и библиотеки не загружаются. Для удобного доступа с телефона используй опубликованную ссылку.

## Содержание и прогресс

Ответы перенесены из исходных карточек и не прошли математическую проверку. Прогресс хранится только в текущем браузере через localStorage, не отправляется на сервер и не синхронизируется с Anki или друзьями. При открытии локального файла браузер может ограничивать сохранение прогресса.

Служебные идентификаторы Library и метаданные исходной коллекции удалены из этой публичной сборки. Учебные тексты сохранены; перед открытой публикацией убедись, что имеешь право их распространять. Этот комплект не устанавливает новую лицензию на учебные материалы. Лицензия встроенной библиотеки KaTeX сохранена в `vendor/katex/LICENSE`.
